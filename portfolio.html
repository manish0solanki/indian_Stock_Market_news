Import Portfolio

Supports both transaction files and holdings snapshots. For holdings reports, MarketPulse reads Script Name, Quantity, Avg Unit Cost, and Status, resolves the NSE symbol, and creates an initial BUY position. Current Price / Current Value / Unrealized P&L are recalculated from the live price feed. Because a holdings snapshot has no original trade date, imported rows use today's date and are marked as CSV snapshot imports. Existing transactions are not deleted.
