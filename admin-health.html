The data health dashboard is for MarketPulse admins only.

Database checks compare each feed's newest data with what should exist right now: live feeds are strict during NSE hours (Mon–Fri 09:15–15:30 IST) and only need the last session's data otherwise, so evenings and weekends don't raise false alarms. Exchange holidays aren't known, so a holiday can show market-hours feeds as late. Live checks call each backend function from this browser. The page re-checks every 2 minutes while open.
